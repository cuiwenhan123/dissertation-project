Methodology

Research framing, experimental variables, metrics, and reproducibility notes for the robustness evaluation.

Research question

How do image degradations affect transformer-based object detection?

The system evaluates whether a DETR-style detector remains reliable when image quality is reduced by blur, low illumination, or compression artefacts.

Models

Transformer vs CNN baseline

DETR ResNet-50 and Faster R-CNN ResNet-50 FPN run from fixed local COCO-pretrained weights. The primary robustness study keeps both models frozen for a fair baseline.

Independent variables

Dataset, degradation, severity

Experiments apply directional motion blur, seeded low-light noise, and JPEG compression at recorded severity levels from 0 to 5.

Dependent measures

COCO mAP, AP50, AP75, AR100

Metrics are calculated with pycocotools COCOeval, including small, medium, and large object AP/AR plus one-to-one failure analysis.

Robustness trend

Severity curves across degradations

The Curves page converts benchmark rows into mAP trends, making degradation sensitivity easier to compare between model families.

Failure modes

Missed, classification, localisation, false positive

Failure analysis translates raw metrics into interpretable categories that can be discussed in the dissertation results chapter.

Reproducibility

Exportable benchmark evidence

Each SQLite record stores dataset and model SHA-256 hashes, package versions, random seed, score threshold, and exact degradation settings.
